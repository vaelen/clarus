# 68k Peephole Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deterministic peephole pass over cg68k's instruction arena that measurably speeds up and shrinks native 68k output, with a compiler-shaped benchmark and size meter proving every pattern's contribution.

**Architecture:** New `clarusc/peep68k.cla` module with entry point `peepFunc(startIdx)` called at the tail of `cgEmitFunc` (so the measure and emit passes agree byte-for-byte); rewrites mark items dead (`KindDead`) rather than removing them; a new `a68Relayout(fromIdx)` in asm68k re-derives addresses/lengths/label binds after rewriting. Spec: `docs/superpowers/specs/2026-08-08-peephole68k-design.md`.

**Tech Stack:** Clarus (clarusc compiler sources), Go test harnesses (`internal/cg68k`, `internal/mactest`), vasm oracle, Mini vMac native lane.

## Global Constraints

- Feature branch `peephole68k`; merge only on Andrew's request.
- Run `scripts/test-task.sh --smoke` after every task (this phase touches `clarusc/`), FOREGROUND — never background a gated test run (standing SDD lesson).
- All edits to `.cla` files must stay pure ASCII. Never introduce non-ASCII bytes; if you ever must touch an existing high-byte (MacRoman) literal, use `LC_ALL=C sed`, not the Edit tool.
- Rewrites must be same-size-or-smaller and only touch `KindInstr` items between barriers. Never rewrite across `KindBind`/`KindTrap`/`KindData` or any control-flow instruction. Never grow an item.
- All instruction lengths are even (2/4/6 bytes), so rewrites never change parity — `DKindAlign` decisions made at emit time stay valid. Do not add any pattern that could change parity.
- The pass must be a pure function of the item list: patterns never read `it.addr` (layout is re-derived by `a68Relayout` afterward).
- cprint/host path untouched. No language-surface changes, no reference edits.
- The committed snapshot `clarusc/clarusc.c` is regenerated ONCE, in Task 9 — not per task. Mid-branch, T1 stays green because the snapshot-freshness gates live in T2-only `internal/selfhost`.
- Commit messages end with the standard co-author trailer.

## Verified codebase facts (for implementers with zero context)

- `clarusc/asm68k.cla`: `record A68Item` (fields `kind, op, size, sm, sr, sv, dm, dr, dv, label, trapWord, trapName, dataKind, dataVal, dataText, commentText, addr, len`); arena `var a68Items: list of A68Item`; kind consts `KindInstr=0 KindBind=1 KindData=2 KindTrap=3 KindComment=4`; enums `A68Op` (`OpMove`, `OpAdda`, `OpAddq`, `OpClr`, `OpBra`, `OpBcc`, `OpBsr`, `OpJsr`, `OpJmp`, `OpRts`, `OpScc`, `OpCmp`, `OpTst`, …) and `A68Mode` (`AmNone AmDn AmAn AmInd AmPostInc AmPreDec AmDisp16 AmPCLabel AmImm AmAbsW`). `size` is the byte width: 1/2/4 (0 for sizeless ops like LINK/UNLK/RTS).
- `a68PushInstr` computes `it.len = 2 + a68InstrExtWords(op, size, sm, dm) * 2` and advances `a68Pc`; `a68Bind(l)` sets `a68LabelAddr[l] = a68Pc` eagerly and appends a zero-length `KindBind` item carrying `label = l`; only `a68Finish` encodes bytes (walking the arena calling `a68EncodeItem`), and the listing printer `a68ListingLine` reads the same items.
- `clarusc/cg68k.cla`: `cgEmitFunc(f)` (line ~3243) has an early `return` for callback glue (`cgCbGlueBodyFor(f) != -1`) and otherwise ends with `a68Bind(cgCurEpilogueLabel)` / `OpUnlk` / `OpRts`. The binary-op discipline (`cgArith` ~4428, `cgCompare` ~4384): left value in D0, `a68Emit(OpMove, 4, AmDn, 0, 0, AmPreDec, 7, 0)` (push), evaluate right into D0, `a68Emit(OpMove, 4, AmPostInc, 7, 0, AmDn, 1, 0)` (pop into D1), then the operator with D1=left, D0=right. `CMP` is emitted as `a68Emit(OpCmp, 4, AmDn, 0, 0, AmDn, 1, 0)` — direction matters, so D1=left/D0=right must be preserved by every rewrite.
- `cgLoadVar` (~4104): 1-byte loads emit `OpClr,4,→D0` then `OpMove,1,AmDisp16(reg,off),→D0`; 4-byte loads emit one `OpMove,4,AmDisp16,→D0`. `cgCleanupStack(n)` (~6773): `OpAddq,4,AmImm,sv=n,→AmAn,7` for n≤8, else `OpAdda,2,AmImm,sv=n,→AmAn,7`.
- Flags in `clarusc/main.cla`: emit68k-only flags are matched in the arg loop near line 494 (`--listing`, `--seglimit`, `--events`); `listingFlag` is passed to `cg68Program(outPath, listingFlag, segLimitFlag)` (line ~1218). `--listing` makes `cg68Program` write per-segment `<base>.segN.s` (listing) and `<base>.segN.dat` (raw bytes) files.

#!/bin/sh
# size-68k.sh -- emitted-native-size meter (peephole68k phase, Task 1).
# Builds the CURRENT compiler (two-stage from the committed snapshot),
# emit68k's three representative programs with --listing, and reports
# total CODE bytes + segment count per target:
#   SIZE <name> bytes=<sum of .segN.dat> segments=<N> bin=<bin size>
# Deterministic and host-only; used to record before/after numbers for
# every peephole pattern.
set -e
cd "$(dirname "$0")/.."

work=$(mktemp -d)
trap 'rm -rf "$work"' EXIT

cc -O1 -I runtime/host -o "$work/boot" clarusc/clarusc.c runtime/host/rt.c
"$work/boot" emit --rtdir runtime/clarus/ -o "$work/cur.c" clarusc/main.cla
cc -O1 -I runtime/host -o "$work/cur" "$work/cur.c" runtime/host/rt.c

measure() {
    name=$1; shift
    out="$work/$name"
    "$work/cur" emit68k --rtdir runtime/clarus/ --listing -o "$out.bin" "$@"
    bytes=0
    segs=0
    for d in "$out".seg*.dat; do
        [ -f "$d" ] || continue
        bytes=$((bytes + $(wc -c < "$d")))
        segs=$((segs + 1))
    done
    printf 'SIZE %s bytes=%d segments=%d bin=%d\n' \
        "$name" "$bytes" "$segs" "$(wc -c < "$out.bin")"
}

measure clarusc clarusc/main.cla
measure coregui --testapi testsuite/kit.cla testsuite/core/runner.cla \
    testsuite/core/cases_*.cla testsuite/core/gui.cla
measure toolboxgui --testapi testsuite/kit.cla testsuite/toolbox/runner.cla \
    testsuite/toolbox/cases_*.cla testsuite/toolbox/gui.cla
```

// a68Relayout re-derives layout for the arena tail [fromIdx..count)
// after a peephole rewrite (peep68k.cla): each item's len (from the same
// per-op table a68PushInstr consulted), each item's addr, every KindBind
// label address in the range, and the running a68Pc. Layout is DERIVED
// state -- patterns edit op/mode/value fields and kinds only, never addr
// -- so one forward walk re-establishes everything a68Finish and the
// listing printer need. Rewrites never touch items before fromIdx, so
// the tail's starting address is the untouched a68Items[fromIdx].addr.
// DKindAlign lengths are kept as emitted: every instruction length is
// even, so a rewrite can never change parity (see peep68k.cla's own
// same-size-or-smaller rule).
func a68Relayout(fromIdx: int) {
    var i: int
    var pc: int
    var it: A68Item

    if fromIdx >= a68Items.count {
        return
    }
    pc = a68Items[fromIdx].addr
    i = fromIdx
    while i < a68Items.count {
        it = a68Items[i]
        if it.kind == KindInstr {
            it.len = 2 + a68InstrExtWords(it.op, it.size, it.sm, it.dm) * 2
        } else if it.kind == KindDead {
            it.len = 0
        }
        it.addr = pc
        a68Items[i] = it
        if it.kind == KindBind {
            a68LabelAddr[it.label] = pc
        }
        pc = pc + it.len
        i = i + 1
    }
    a68Pc = pc
}
```

- [ ] **Step 2: Create clarusc/peep68k.cla**

```
// Copyright 2026, Andrew C. Young <andrew@vaelen.org>
// SPDX-License-Identifier: MIT

// peep68k.cla -- peephole pass over asm68k's instruction arena
// (peephole68k phase; spec:
// docs/superpowers/specs/2026-08-08-peephole68k-design.md).
//
// peepFunc(startIdx) runs at the tail of cgEmitFunc, over exactly the
// items that function just emitted. Because cg68Measure sizes functions
// by calling the real cgEmitFunc, the pass runs identically under
// measurement and emission -- segment packing stays exact by
// construction.
//
// SAFETY RULES (every pattern MUST obey; see the spec's "Safety rules"):
//   - a match window never spans a KindBind (control can enter there),
//     any control-flow/call instruction (Bcc/BRA/BSR/JSR/JMP/DBRA/RTS),
//     a KindTrap, or KindData;
//   - KindComment/KindDead are transparent (peepNextReal skips them);
//   - rewrites are same-size-or-smaller, and all instruction sizes are
//     even, so parity (DKindAlign) is never disturbed;
//   - patterns match EXACT op/size/mode/register shapes -- no general
//     effect analysis. Whitelists over naive codegen's actual shapes;
//   - patterns never read it.addr (a68Relayout re-derives layout after).

// peepDisabled: set by main.cla's --nopeep (emit68k-only diagnostic
// flag). Default false = pass enabled.
var peepDisabled: bool

// peepNextReal returns the index of the next non-transparent item after
// i (skipping KindComment and KindDead), or -1 at arena end. The caller
// checks the returned item's kind/shape itself -- including whether it
// is a barrier.
func peepNextReal(i: int): int {
    var j: int

    j = i + 1
    while j < a68Items.count {
        if a68Items[j].kind != KindComment and a68Items[j].kind != KindDead {
            return j
        }
        j = j + 1
    }
    return -1
}

// peepKill marks item i deleted (KindDead, zero length).
func peepKill(i: int) {
    var it: A68Item

    it = a68Items[i]
    it.kind = KindDead
    it.len = 0
    a68Items[i] = it
}

// peepIsSimpleLoadToD0: item i is a single instruction that fully
// defines D0 without reading D0 or D1 and without touching A7 --
// naive codegen's own load shapes:
//   MOVE.L #imm,D0            (AmImm -> D0)
//   MOVE.L d16(An),D0, An!=A7 (AmDisp16 -> D0; A7 excluded because a
//                              pattern may be deleting a push above it,
//                              which would shift an A7-relative offset)
// Deliberately NOT whitelisted: AmDn sources (could read D1), AmPostInc/
// AmPreDec (mutate their base register), byte/word loads (upper bytes
// of D0 not defined), anything writing other registers.
func peepIsSimpleLoadToD0(i: int): bool {
    var it: A68Item

    it = a68Items[i]
    if it.kind != KindInstr { return false }
    if it.op != OpMove { return false }
    if it.size != 4 { return false }
    if it.dm != AmDn or it.dr != 0 { return false }
    if it.sm == AmImm { return true }
    if it.sm == AmDisp16 and it.sr != 7 { return true }
    return false
}

// peepFunc: run all patterns over [startIdx..count) to fixpoint, then
// re-derive layout. Patterns are added per task; each returns true if
// it changed anything this sweep.
func peepFunc(startIdx: int) {
    var changed: bool
    var any: bool

    if peepDisabled {
        return
    }
    any = false
    changed = true
    while changed {
        changed = false
        // (pattern calls land here in Tasks 4-8, e.g.:
        //  if peepPassPushPop(startIdx) { changed = true } )
        if changed {
            any = true
        }
    }
    if any {
        a68Relayout(startIdx)
    }
}
```

// caller-cleans stack cleanups merged when everything between them is
// A7-neutral. Delaying a stack POP is always safe (SP stays lower, the
// dead bytes stay allocated; nothing between reads or writes through
// A7 by whitelist), so the FIRST cleanup dies and its count folds into
// the second. Cleanup shapes are exactly cgCleanupStack's two:
//   ADDQ.L #n,A7 (n<=8)   ADDA.W #n,A7
// A7-neutral whitelist between the two: MOVE (any size) whose source
// and destination modes are each AmDn or AmDisp16-with-base != A7, or
// AmImm source. Scan is bounded (4 real items) to keep the pass linear.
// Merged count: ADDQ.L if <=8 else ADDA.W; skip the merge entirely if

func peepIsStackCleanup(i: int): bool {

    it = a68Items[i]
    if it.kind != KindInstr { return false }
    if it.dm != AmAn or it.dr != 7 or it.sm != AmImm { return false }
    if it.op == OpAddq and it.size == 4 { return true }
    if it.op == OpAdda and it.size == 2 { return true }
    return false
}

func peepIsA7Neutral(i: int): bool {
    var it: A68Item

    it = a68Items[i]
    if it.kind != KindInstr { return false }
    if it.op != OpMove { return false }
    if it.sm != AmDn and it.sm != AmImm and it.sm != AmDisp16 { return false }
    if it.sm == AmDisp16 and it.sr == 7 { return false }
    if it.dm != AmDn and it.dm != AmDisp16 { return false }
    if it.dm == AmDisp16 and it.dr == 7 { return false }
    return true
}

func peepPassCleanupBatch(startIdx: int): bool {
    var i: int
    var j: int
    var hops: int
    var sum: int
    var second: A68Item
    var didChange: bool

    didChange = false
    i = startIdx
    while i < a68Items.count {
        if peepIsStackCleanup(i) {
            j = peepNextReal(i)
            hops = 0
            while j != -1 and hops < 4 and peepIsA7Neutral(j) {
                j = peepNextReal(j)
                hops = hops + 1
            }
            if j != -1 and peepIsStackCleanup(j) {
                sum = a68Items[i].sv + a68Items[j].sv
                if sum <= 32760 {
                    second = a68Items[j]
                    second.sv = sum
                    if sum <= 8 {
                        second.op = OpAddq
                        second.size = 4
                    } else {
                        second.op = OpAdda
                        second.size = 2
                    }
                    a68Items[j] = second
                    peepKill(i)
                    didChange = true
                }
            }
        }
        i = i + 1
    }
    return didChange
}
