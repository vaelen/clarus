# MacTCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TCP as `connection`'s third transport (`c.open(tcp "a.b.c.d:port")`) and `listener`'s second (`l.listen(tcp port)`), through MacTCP's `.IPP` driver on the Macintosh and BSD sockets on the host, plus the three debts parked for this phase (dispatcher-builder fold, `delay N` script verb, AppleTalk in the `--testapi` early-visible set).

**Architecture:** A lane-neutral state machine in `runtime/clarus/tcp.cla` (per-connection-slot phase, pending-send queue, listener re-arm) over a narrow per-lane waist: `tcp_68k.cla` drives MacTCP with polled asynchronous parameter blocks and no ASR, exactly `atalk_68k.cla`'s discipline; `tcp_c.cla` binds `runtime/host/rt_tcp.inc`, one non-blocking fd per slot. `conn.cla`'s open/send/close/pump gain a third transport arm; `atalk.cla`'s listener table gains a transport tag. The compiler learns one contextual keyword. Hardware proof is a Snow (System 7 Mac II, DaynaPORT NAT) self-connect boot at the very end; T1 proves the host lane end to end against `tcpdrive`.

**Tech Stack:** Clarus (`clarusc/*.cla`, `runtime/clarus/*.cla`, `toolbox/*.cla`), C host glue (`runtime/host/*.inc`), POSIX-sh harness (`tests/`), Snow emulator (`snow/`), Universal Interfaces `MacTCP.h` at `Retro68/InterfacesAndLibraries/Interfaces/CIncludes/MacTCP.h` (CR-only line endings: read via `LC_ALL=C tr '\r' '\n' < FILE`), the *MacTCP Programmer's Guide* PDF at `inside-macintosh-v2/MacTCP Programmers Guide.pdf` (Read tool, `pages` parameter).

**Spec:** `docs/superpowers/specs/2026-09-07-mactcp-design.md` — read it first; every task argues from it. Its §5.1 carries the parameter-block offsets, §5.4 the lifecycle, §9 the probes.

## Shared interface: the TCP waist (Tasks 5, 6, 7 all implement or consume it)

`tcp.cla` (lane-neutral) calls exactly these, which `tcp_68k.cla` (MacTCP) and `tcp_c.cla` (host, via `rt_ext_TcpH*` in `rt_tcp.inc`) each define with these exact names and signatures. Slots: connection slots are 0–7 (`rtConnMax`), listener slots 0–1 (`rtLsnMax`). Every error is an `int`: a MacTCP OSErr (negative, e.g. -23015 `openFailed`) on the Mac, a positive errno on the host, 0 for success. `rtTcpErrNoDriver = -23000` (`ipBadLapErr`) is what both lanes return from `rtTcpDevInit` when there is no TCP stack (host: never; Mac: `.IPP` failed to open).

```
// One-time; idempotent. 0, or the error that means "no MacTCP here".
func rtTcpDevInit(): int
// Allocate a connection slot's stream + buffers (Mac: TCPCreate with an
// 8 KB stream buffer, a 4 KB receive copy buffer, a 4 KB send chunk, two
// PBs, a WDS). Host: no-op. 0 or error.
func rtTcpDevCreate(slot: int): int
// Start the asynchronous active open (Mac: TCPActiveOpen, ULP 30 s abort;
// host: non-blocking connect). ip is the packed big-endian quad
// (a<<24|b<<16|c<<8|d), port 1..65535. 0 = started, else error.
func rtTcpDevActiveOpen(slot: int, ip: int, port: int): int
// Poll a connection slot. Returns rtTcpEvNone (0), rtTcpEvOpened (1),
// rtTcpEvReceived (2: bytes are in the receive copy buffer), rtTcpEvClosed
// (3: peer closed or connection terminated), rtTcpEvSent (4: the in-flight
// send completed), or a negative/positive error (the open failed; the slot
// is torn down by the waist). At most ONE event per call; call again for
// the next.
func rtTcpDevPoll(slot: int): int
// After rtTcpEvReceived: how many bytes, and where. Valid until RecvArm.
func rtTcpDevRecvLen(slot: int): int
func rtTcpDevRecvPtr(slot: int): ptr
// Re-issue the receive (Mac: next async TCPRcv; host: no-op). 0 or error.
func rtTcpDevRecvArm(slot: int): int
// true while a send is in flight (Mac: send PB pending; host: unwritten
// remainder of the last chunk).
func rtTcpDevSendBusy(slot: int): bool
// Copy n (1..4096) bytes from p into the slot's send chunk and start the
// send (Mac: TCPSend pushFlag=1; host: write, keep any remainder). 0 or error.
func rtTcpDevSend(slot: int, p: ptr, n: int): int
// Graceful close of OUR half (Mac: TCPClose ULP 10 s abort; host:
// shutdown(SHUT_WR) + a 10 s wall-clock deadline after which Poll reports
// rtTcpEvClosed). 0 or error.
func rtTcpDevClose(slot: int): int
// Abort whatever is left, release the stream, dispose every block. Safe on
// any slot in any state, twice.
func rtTcpDevRelease(slot: int)
// Listener: create the listening stream and start the passive open (Mac:
// TCPCreate + TCPPassiveOpen wildcard, commandTimeout 0; host: socket/
// bind/listen once, idempotent while already listening). 0 or error.
func rtTcpDevLsnOpen(lsn: int, port: int): int
// 0 nothing, 1 a client is ready, <0 the listener itself failed.
func rtTcpDevLsnPoll(lsn: int): int
// Move the ready connection into connection slot `slot` (Mac: the stream
// and its buffers move; the slot's copy/send buffers and PBs are
// allocated; the first receive is armed. Host: the accepted fd moves).
// 0 or error. tcp.cla then calls rtTcpDevLsnOpen again to re-arm.
func rtTcpDevLsnAccept(lsn: int, slot: int): int
// Abort + release the ready connection without accepting it.
func rtTcpDevLsnDeny(lsn: int)
// Abort + release the listening stream / close the listening fd.
func rtTcpDevLsnClose(lsn: int)
```

const rtTcpEvOpened: int = 1

const rtTcpEvSent: int = 4

const rtTcpErrBadSpec: int = -2        // reuses conn.cla's rtConnErrInvalidSpec value

```c
/* runtime/host/rt_tcp.inc -- host BSD-socket glue for the `connection`
 * type's TCP transport (MacTCP phase, Task 5). #included at the bottom of
 * rt.c after rt_atalk.inc. The native twin is runtime/clarus/tcp_68k.cla
 * (MacTCP through .IPP); both answer the same waist tcp.cla calls, listed
 * in docs/superpowers/plans/2026-09-07-mactcp.md.
 *
 * Every fd is O_NONBLOCK. Poll is one pass, no select: the CLI lifetime
 * pump calls it every iteration. Errors are positive errnos, 0 = ok;
 * errno values 1..4 collide with the event codes so they are reported
 * as EIO. */
#include <sys/socket.h>
#include <netinet/in.h>
#include <netinet/tcp.h>
#include <arpa/inet.h>
#include <fcntl.h>
#include <poll.h>
#include <sys/time.h>

#define RT_TCP_SLOTS 8
#define RT_TCP_LSNS  2
#define RT_TCP_CHUNK 4096
#define RT_TCP_CLOSE_SECS 10

enum { RT_TCP_IDLE = 0, RT_TCP_CONNECTING, RT_TCP_OPEN, RT_TCP_CLOSING };

typedef struct {
    int fd;
    int state;
    uint8_t rcv[RT_TCP_CHUNK];
    int32_t rcvLen;          /* bytes in rcv after a received event */
    uint8_t snd[RT_TCP_CHUNK];
    int32_t sndLen, sndOff;  /* unwritten remainder of the last chunk */
    int sentPending;         /* report event 4 once after the chunk drains */
    time_t closeDeadline;    /* RT_TCP_CLOSING: report 3 at the latest here */
} rt_tcp_slot;

typedef struct { int fd; int ready; } rt_tcp_lsn;   /* ready: accepted fd, or -1 */

static rt_tcp_slot rt_tcp_slots[RT_TCP_SLOTS];
static rt_tcp_lsn  rt_tcp_lsns[RT_TCP_LSNS] = { { -1, -1 }, { -1, -1 } };
static int rt_tcp_inited = 0;

static int32_t rt_tcp_err(void) { int e = errno; return e > 4 ? e : EIO; }
static void rt_tcp_nonblock(int fd) { int f = fcntl(fd, F_GETFL, 0); fcntl(fd, F_SETFL, f | O_NONBLOCK); }
static int rt_tcp_slot_ok(int32_t s) { return s >= 0 && s < RT_TCP_SLOTS; }
static int rt_tcp_lsn_ok(int32_t l) { return l >= 0 && l < RT_TCP_LSNS; }
static void rt_tcp_reset(rt_tcp_slot *s) { if (s->fd >= 0) close(s->fd); memset(s, 0, sizeof *s); s->fd = -1; }

int32_t rt_ext_TcpHInit(void) {
    if (!rt_tcp_inited) { int i; for (i = 0; i < RT_TCP_SLOTS; i++) { rt_tcp_slots[i].fd = -1; } rt_tcp_inited = 1; }
    rt_conn_ignore_sigpipe();
    return 0;
}
int32_t rt_ext_TcpHCreate(int32_t slot) { return rt_tcp_slot_ok(slot) ? 0 : EINVAL; }

int32_t rt_ext_TcpHActiveOpen(int32_t slot, int32_t ip, int32_t port) {
    struct sockaddr_in sa; int fd;
    if (!rt_tcp_slot_ok(slot) || port <= 0 || port > 65535) return EINVAL;
    rt_tcp_reset(&rt_tcp_slots[slot]);
    fd = socket(AF_INET, SOCK_STREAM, 0);
    if (fd < 0) return rt_tcp_err();
    rt_tcp_nonblock(fd);
    memset(&sa, 0, sizeof sa);
    sa.sin_family = AF_INET; sa.sin_addr.s_addr = htonl((uint32_t)ip); sa.sin_port = htons((uint16_t)port);
    if (connect(fd, (struct sockaddr *)&sa, sizeof sa) < 0 && errno != EINPROGRESS) { int e = rt_tcp_err(); close(fd); return e; }
    rt_tcp_slots[slot].fd = fd; rt_tcp_slots[slot].state = RT_TCP_CONNECTING;
    return 0;
}

/* rt_tcp_flush: write the pending remainder; 0 ok, errno on a hard error. */
static int32_t rt_tcp_flush(rt_tcp_slot *s) {
    while (s->sndOff < s->sndLen) {
        ssize_t n = send(s->fd, s->snd + s->sndOff, (size_t)(s->sndLen - s->sndOff), 0);
        if (n < 0) { if (errno == EAGAIN || errno == EWOULDBLOCK) return 0; return rt_tcp_err(); }
        s->sndOff += (int32_t)n;
    }
    if (s->sndLen > 0) { s->sndLen = s->sndOff = 0; s->sentPending = 1; }
    return 0;
}

int32_t rt_ext_TcpHPoll(int32_t slot) {
    rt_tcp_slot *s; struct pollfd p; int so_err; socklen_t sl = sizeof so_err; ssize_t n;
    if (!rt_tcp_slot_ok(slot)) return EINVAL;
    s = &rt_tcp_slots[slot];
    if (s->state == RT_TCP_IDLE) return 0;
    if (s->state == RT_TCP_CONNECTING) {
        p.fd = s->fd; p.events = POLLOUT; p.revents = 0;
        if (poll(&p, 1, 0) <= 0) return 0;
        if (getsockopt(s->fd, SOL_SOCKET, SO_ERROR, &so_err, &sl) < 0 || so_err != 0) {
            int e = so_err > 4 ? so_err : EIO; rt_tcp_reset(s); return e;
        }
        s->state = RT_TCP_OPEN; return 1;
    }
    /* OPEN or CLOSING: drain sends first, then one receive. */
    if (s->sndLen > 0) { int32_t e = rt_tcp_flush(s); if (e) { rt_tcp_reset(s); return 3; } }
    if (s->sentPending) { s->sentPending = 0; return 4; }
    if (s->rcvLen > 0) return 0;   /* the last received event is not consumed yet */
    n = recv(s->fd, s->rcv, sizeof s->rcv, 0);
    if (n > 0) { s->rcvLen = (int32_t)n; return 2; }
    if (n == 0 || (errno != EAGAIN && errno != EWOULDBLOCK)) { rt_tcp_reset(s); return 3; }
    if (s->state == RT_TCP_CLOSING && time(NULL) >= s->closeDeadline) { rt_tcp_reset(s); return 3; }
    return 0;
}
int32_t rt_ext_TcpHRecvLen(int32_t slot) { return rt_tcp_slot_ok(slot) ? rt_tcp_slots[slot].rcvLen : 0; }
void   *rt_ext_TcpHRecvPtr(int32_t slot) { return rt_tcp_slot_ok(slot) ? rt_tcp_slots[slot].rcv : NULL; }
int32_t rt_ext_TcpHRecvArm(int32_t slot) { if (rt_tcp_slot_ok(slot)) rt_tcp_slots[slot].rcvLen = 0; return 0; }
int32_t rt_ext_TcpHSendBusy(int32_t slot) { return rt_tcp_slot_ok(slot) && rt_tcp_slots[slot].sndLen > 0; }
int32_t rt_ext_TcpHSend(int32_t slot, void *p, int32_t n) {
    rt_tcp_slot *s;
    if (!rt_tcp_slot_ok(slot) || n <= 0 || n > RT_TCP_CHUNK) return EINVAL;
    s = &rt_tcp_slots[slot];
    if (s->state != RT_TCP_OPEN && s->state != RT_TCP_CLOSING) return ENOTCONN;
    if (s->sndLen > 0) return EBUSY;
    memcpy(s->snd, p, (size_t)n); s->sndLen = n; s->sndOff = 0;
    return rt_tcp_flush(s);
}
int32_t rt_ext_TcpHClose(int32_t slot) {
    rt_tcp_slot *s;
    if (!rt_tcp_slot_ok(slot)) return EINVAL;
    s = &rt_tcp_slots[slot];
    if (s->state != RT_TCP_OPEN) return 0;
    shutdown(s->fd, SHUT_WR);
    s->state = RT_TCP_CLOSING; s->closeDeadline = time(NULL) + RT_TCP_CLOSE_SECS;
    return 0;
}
void rt_ext_TcpHRelease(int32_t slot) { if (rt_tcp_slot_ok(slot)) rt_tcp_reset(&rt_tcp_slots[slot]); }

int32_t rt_ext_TcpHLsnOpen(int32_t lsn, int32_t port) {
    int fd, yes = 1; struct sockaddr_in sa;
    if (!rt_tcp_lsn_ok(lsn) || port <= 0 || port > 65535) return EINVAL;
    if (rt_tcp_lsns[lsn].fd >= 0) return 0;      /* already listening: re-arm is a no-op */
    fd = socket(AF_INET, SOCK_STREAM, 0);
    if (fd < 0) return rt_tcp_err();
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &yes, sizeof yes);
    memset(&sa, 0, sizeof sa);
    sa.sin_family = AF_INET; sa.sin_addr.s_addr = htonl(INADDR_ANY); sa.sin_port = htons((uint16_t)port);
    if (bind(fd, (struct sockaddr *)&sa, sizeof sa) < 0 || listen(fd, 4) < 0) { int e = rt_tcp_err(); close(fd); return e; }
    rt_tcp_nonblock(fd);
    rt_tcp_lsns[lsn].fd = fd; rt_tcp_lsns[lsn].ready = -1;
    return 0;
}
int32_t rt_ext_TcpHLsnPoll(int32_t lsn) {
    int c;
    if (!rt_tcp_lsn_ok(lsn) || rt_tcp_lsns[lsn].fd < 0) return -EINVAL;
    if (rt_tcp_lsns[lsn].ready >= 0) return 1;
    c = accept(rt_tcp_lsns[lsn].fd, NULL, NULL);
    if (c < 0) return (errno == EAGAIN || errno == EWOULDBLOCK || errno == EINTR) ? 0 : -rt_tcp_err();
    rt_tcp_nonblock(c); rt_tcp_lsns[lsn].ready = c;
    return 1;
}
int32_t rt_ext_TcpHLsnAccept(int32_t lsn, int32_t slot) {
    if (!rt_tcp_lsn_ok(lsn) || !rt_tcp_slot_ok(slot) || rt_tcp_lsns[lsn].ready < 0) return EINVAL;
    rt_tcp_reset(&rt_tcp_slots[slot]);
    rt_tcp_slots[slot].fd = rt_tcp_lsns[lsn].ready; rt_tcp_slots[slot].state = RT_TCP_OPEN;
    rt_tcp_lsns[lsn].ready = -1;
    return 0;
}
void rt_ext_TcpHLsnDeny(int32_t lsn) {
    if (rt_tcp_lsn_ok(lsn) && rt_tcp_lsns[lsn].ready >= 0) {
        struct linger lg = { 1, 0 };   /* RST, not FIN: "the client sees a reset" */
        setsockopt(rt_tcp_lsns[lsn].ready, SOL_SOCKET, SO_LINGER, &lg, sizeof lg);
        close(rt_tcp_lsns[lsn].ready); rt_tcp_lsns[lsn].ready = -1;
    }
}
void rt_ext_TcpHLsnClose(int32_t lsn) {
    if (!rt_tcp_lsn_ok(lsn)) return;
    rt_ext_TcpHLsnDeny(lsn);
    if (rt_tcp_lsns[lsn].fd >= 0) { close(rt_tcp_lsns[lsn].fd); rt_tcp_lsns[lsn].fd = -1; }
}

// Copyright 2026, Andrew C. Young <andrew@vaelen.org>
// SPDX-License-Identifier: MIT

// tcp.cla: the shared TCP runtime (MacTCP phase, spec §5). conn.cla's
// third transport (tag 3) and listener's second form. Lane-neutral: every
// device-facing call goes through the rtTcpDev* waist -- tcp_68k.cla
// (MacTCP through .IPP, polled async parameter blocks, no ASR) and
// tcp_c.cla (BSD sockets via runtime/host/rt_tcp.inc) -- listed in the
// plan's "Shared interface" section.
//
// Spliced after conn.cla and atalk.cla on both lanes (host: with them,
// under `usesConn or usesAtalk`; 68k: the unconditional superset). Reads
// conn.cla's slot table (rtConnState, rtConnSlotTransport, the fire
// externs) and atalk.cla's listener table (rtLsnState, rtLsnSetFailed,
// rtAtAppendBytes).
//
// Error principle (inherited): contract violations panic (nil resource,
// send on a non-open slot); everything environmental is a staged `failed`
// drained by the next pump pass, never fired from the call that caused it.
//
// Slot ownership: a slot is TCP's from rtTcpOpen/accept until rtTcpRelease
// -- through Closing, even after conn.cla has marked it stClosed for the
// user. rtConnClose must NOT clear rtConnSlotTransport for tag 3 (the
// pump would stop polling the lingering close); this module clears it at
// release, as atalk.cla's rtAdspFailed does for ADSP.

const rtConnTransportTcp: int = 3
const rtTcpEvNone: int = 0
const rtTcpEvOpened: int = 1
const rtTcpEvReceived: int = 2
const rtTcpEvClosed: int = 3
const rtTcpEvSent: int = 4
const rtTcpErrNoDriver: int = -23000
const rtTcpErrBadSpec: int = -2
const rtTcpStreamBuf: int = 8192
const rtTcpChunk: int = 4096

// Phases, per connection slot.
const rtTcpIdle: int = 0
const rtTcpOpening: int = 1
const rtTcpEstablished: int = 2
const rtTcpClosing: int = 3

var rtTcpPhase: int[8]
var rtTcpPending: text[8]        // bytes queued behind the in-flight send
var rtTcpUp: bool                // rtTcpDevInit succeeded once
var rtLsnSlotTransport: int[2]   // 0 ADSP/unused, 3 TCP
var rtLsnPort: int[2]
var rtTcpLastErr: int

// rtTcpParseIp/rtTcpParsePort: rtTcpParseSpec's out-params (no int by-ref).
var rtTcpParseIp: int
var rtTcpParsePort: int

// rtTcpParseSpec: "a.b.c.d:port" -> packed big-endian ip + port. false on
// anything else -- including a host NAME, which is the DNR phase's job on
// both lanes (spec Q3).
func rtTcpParseSpec(spec: string): bool {
    var colonIdx: int
    var host: string
    var i: int
    var start: int
    var octets: int
    var v: int
    var ip: int

    colonIdx = spec.indexOf(':')
    if colonIdx <= 0 {
        return false
    }
    host = spec[0, colonIdx]
    rtTcpParsePort = rtConnParseInt(spec[colonIdx + 1, spec.length - colonIdx - 1])
    if rtTcpParsePort < 1 or rtTcpParsePort > 65535 {
        return false
    }
    ip = 0
    octets = 0
    start = 0
    i = 0
    while i <= host.length {
        if i == host.length or host[i] == '.' {
            if i == start {
                return false
            }
            v = rtConnParseInt(host[start, i - start])
            if v < 0 or v > 255 {
                return false
            }
            ip = ip * 256 + v
            octets = octets + 1
            start = i + 1
        }
        i = i + 1
    }
    if octets != 4 {
        return false
    }
    rtTcpParseIp = ip
    return true
}

func rtTcpEnsureUp(): int {
    var e: int

    if rtTcpUp {
        return 0
    }
    e = rtTcpDevInit()
    if e != 0 {
        rtTcpLastErr = e
        return e
    }
    rtTcpUp = true
    return 0
}

// rtTcpFree: the slot is not TCP's (for listener accept scans).
func rtTcpFree(slot: int): bool {
    return rtTcpPhase[slot] == rtTcpIdle
}

// rtTcpRelease: back to Idle, whatever was in flight; clears conn.cla's
// transport tag (the ADSP convention). Idempotent.
func rtTcpRelease(slot: int) {
    rtTcpDevRelease(slot)
    rtTcpPhase[slot] = rtTcpIdle
    rtTcpPending[slot].clear()
    if rtConnSlotTransport[slot] == rtConnTransportTcp {
        rtConnSlotTransport[slot] = 0
    }
}

// rtTcpOpen: conn.cla's transport-3 arm. 0 = started (opened/failed come
// from the pump); nonzero = failed now (conn.cla stages `failed`). A slot
// still lingering in Closing is aborted and reused.
func rtTcpOpen(slot: int, spec: string): int {
    var e: int

    if rtTcpPhase[slot] != rtTcpIdle {
        rtTcpRelease(slot)
    }
    if not rtTcpParseSpec(spec) {
        return rtTcpErrBadSpec
    }
    e = rtTcpEnsureUp()
    if e != 0 {
        return e
    }
    e = rtTcpDevCreate(slot)
    if e != 0 {
        return e
    }
    e = rtTcpDevActiveOpen(slot, rtTcpParseIp, rtTcpParsePort)
    if e != 0 {
        rtTcpDevRelease(slot)
        return e
    }
    rtConnSlotTransport[slot] = rtConnTransportTcp
    rtTcpPhase[slot] = rtTcpOpening
    return 0
}

// rtTcpKick: start the next chunk if nothing is in flight and bytes wait.
func rtTcpKick(slot: int): int {
    var n: int
    var scratch: ptr
    var e: int
    var i: int

    if rtTcpDevSendBusy(slot) or rtTcpPending[slot].length == 0 {
        return 0
    }
    n = rtTcpPending[slot].length
    if n > rtTcpChunk {
        n = rtTcpChunk
    }
    scratch = rtAtTextToPtr(rtTcpPending[slot])   // whole text; the waist copies the first n
    if scratch == ptr(0) {
        return rtAtErrMemFull
    }
    e = rtTcpDevSend(slot, scratch, n)
    SerDisposePtr(scratch)
    if e != 0 {
        return e
    }
    // drop the first n bytes: rebuild the remainder (ponytail: O(len) per
    // chunk; a ring buffer if a 64 KB send ever shows up in a profile).
    rtTcpDropFront(slot, n)
    return 0
}

func rtTcpDropFront(slot: int, n: int) {
    var rest: text
    var i: int

    i = n
    while i < rtTcpPending[slot].length {
        rest.append(rtTcpPending[slot][i])
        i = i + 1
    }
    rtTcpPending[slot].clear()
    rtTcpPending[slot].append(rest)
}

// rtTcpWrite: conn.cla's transport-3 send arm (the slot is stOpen, so the
// phase is Established). Queues, then kicks. Nonzero = a staged `failed`.
func rtTcpWrite(slot: int, p: ptr, n: int): int {
    rtAtAppendBytes(rtTcpPending[slot], p, n)
    return rtTcpKick(slot)
}

// rtTcpClose: conn.cla's transport-3 close arm. Never fires `closed`.
func rtTcpClose(slot: int) {
    if rtTcpPhase[slot] == rtTcpEstablished {
        rtTcpPhase[slot] = rtTcpClosing
        rtTcpStep(slot)
    } else if rtTcpPhase[slot] == rtTcpOpening {
        rtTcpRelease(slot)
    }
}

// rtTcpStep: in Closing, issue the graceful close once the queue drained.
func rtTcpStep(slot: int) {
    if rtTcpPhase[slot] == rtTcpClosing and rtTcpPending[slot].length == 0 and not rtTcpDevSendBusy(slot) {
        rtTcpDevClose(slot)
    }
}

// rtTcpPollConn: conn.cla's rtConnPump arm for a transport-3 slot -- one
// waist event per pass, turned into conn.cla's own state + fire calls.
func rtTcpPollConn(slot: int) {
    var ev: int
    var t: text
    var e: int

    if rtTcpPhase[slot] == rtTcpIdle {
        return
    }
    ev = rtTcpDevPoll(slot)
    if ev == rtTcpEvNone {
        rtTcpStep(slot)
        return
    }
    if ev != rtTcpEvOpened and ev != rtTcpEvReceived and ev != rtTcpEvClosed and ev != rtTcpEvSent {
        // the open failed (MacTCP OSErr < 0, host errno > 4)
        rtTcpRelease(slot)
        rtConnSetFailed(slot, ev, "could not open connection")
        return
    }
    if ev == rtTcpEvOpened {
        rtTcpPhase[slot] = rtTcpEstablished
        rtConnState[slot] = stOpen
        clar_conn_fire_opened(slot)
        return
    }
    if ev == rtTcpEvSent {
        e = rtTcpKick(slot)
        if e != 0 and rtConnPendFailedCode[slot] == 0 {
            rtConnPendFailedCode[slot] = e
            rtConnPendFailedMsg[slot] = "write failed"
        }
        rtTcpStep(slot)
        return
    }
    if ev == rtTcpEvReceived {
        if rtTcpPhase[slot] == rtTcpEstablished {
            t = ""
            rtAtAppendBytes(t, rtTcpDevRecvPtr(slot), rtTcpDevRecvLen(slot))
            rtTcpDevRecvArm(slot)
            clar_conn_fire_received(slot, t)
        } else {
            rtTcpDevRecvArm(slot)   // Closing: bytes after a local close are dropped
        }
        return
    }
    // rtTcpEvClosed
    if rtTcpPhase[slot] == rtTcpEstablished {
        rtTcpRelease(slot)
        rtConnState[slot] = stClosed
        clar_conn_fire_closed(slot)
    } else {
        rtTcpRelease(slot)
    }
}

// ---- listener ----

func rtLsnListen(h: int, port: int) {
    var slot: int
    var e: int

    if h == 0 {
        rtPanic("use of nil listener")
    }
    slot = h - 1
    if rtLsnState[slot] == rtAtActive {
        rtLsnSetFailed(slot, rtConnErrAlreadyOpen, "listener already registered")
        return
    }
    if port < 1 or port > 65535 {
        rtLsnSetFailed(slot, rtTcpErrBadSpec, "invalid port")
        return
    }
    e = rtTcpEnsureUp()
    if e != 0 {
        rtLsnSetFailed(slot, e, "TCP unavailable")
        return
    }
    e = rtTcpDevLsnOpen(slot, port)
    if e != 0 {
        rtLsnSetFailed(slot, e, rtTcpListenMsg(e))
        return
    }
    rtLsnSlotTransport[slot] = rtConnTransportTcp
    rtLsnPort[slot] = port
    rtLsnState[slot] = rtAtActive
}

func rtTcpListenMsg(code: int): string {
    if code == -23017 or code == 48 {   // duplicateSocket / EADDRINUSE
        return "port in use"
    }
    return "could not start listener"
}

// rtTcpLsnStop: atalk.cla's rtLsnStop arm for a TCP listener.
func rtTcpLsnStop(slot: int) {
    rtTcpDevLsnClose(slot)
    rtLsnSlotTransport[slot] = 0
    rtLsnPort[slot] = 0
}

// rtTcpPump: the listeners (connections are polled from rtConnPump).
func rtTcpPump() {
    var i: int
    var pr: int
    var free: int
    var j: int
    var e: int

    i = 0
    while i < rtLsnMax {
        if rtLsnState[i] == rtAtActive and rtLsnSlotTransport[i] == rtConnTransportTcp {
            pr = rtTcpDevLsnPoll(i)
            if pr < 0 {
                rtLsnSetFailed(i, pr, "listener failed")
                rtLsnStop(i + 1)
            } else if pr == 1 {
                free = -1
                j = 0
                while j < rtConnMax {
                    if free < 0 and rtConnState[j] == stClosed and rtAdspPhase[j] == rtAdspNone and rtTcpFree(j) {
                        free = j
                    }
                    j = j + 1
                }
                if free < 0 {
                    rtTcpDevLsnDeny(i)
                } else {
                    e = rtTcpDevLsnAccept(i, free)
                    if e != 0 {
                        rtLsnSetFailed(i, e, "could not accept connection")
                    } else {
                        rtConnState[free] = stOpen
                        rtConnSlotTransport[free] = rtConnTransportTcp
                        rtTcpPhase[free] = rtTcpEstablished
                        clar_lsn_fire_accepted(i, free + 1)
                    }
                }
                e = rtTcpDevLsnOpen(i, rtLsnPort[i])
                if e != 0 {
                    // spec §4.2: a failed re-arm tears the listener down.
                    rtLsnSetFailed(i, e, "listener failed")
                    rtLsnStop(i + 1)
                }
            }
        }
        i = i + 1
    }
}

func rtTcpAlive(): bool {
    var i: int

    i = 0
    while i < rtConnMax {
        if rtTcpPhase[i] != rtTcpIdle {
            return true
        }
        i = i + 1
    }
    return false
}

- [ ] **Step 2: Create, open, receive, send, close, release**

`rtTcpDevCreate(slot)`: allocate the seven blocks (`NewPtrClear`; sizes `rtTcpStreamBuf`, `rtTcpChunk`, `rtTcpChunk`, `tcpPbSize`, `tcpPbSize`, 12) if unallocated; then a sync `TCPCreate` through `rtTcp68Pb[slot]`:

```

    pokew(pb + tcpIoCRefNum, rtTcp68Ref)

```

`rtTcpDevActiveOpen(slot, ip, port)`: zero `rtTcp68Pb`, `csCode = tcpActiveOpen`, `tcpStream`, `ulpTimeoutValue = 30`, `ulpTimeoutAction = tcpUlpAbort`, `validityFlags = tcpValidTimeoutValue | tcpValidTimeoutAction` (`0xC0`), `remoteHost = ip` (pokel), `remotePort = port` (pokew), `localHost = 0`, `localPort = 0`; `PBControlAsync`; on 0 set `rtTcp68PbLive/PbOp = 1`.

`rtTcp68ArmRcv(slot)` (= `rtTcpDevRecvArm`): zero `rtTcp68RcvPb`, `csCode = tcpRcv`, `tcpStream`, `commandTimeoutValue = 0`, `rcvBuff = rtTcp68Rcv[slot]`, `rcvBuffLen = rtTcpChunk`; `PBControlAsync`; `rtTcp68RcvLive = true`.

`rtTcpDevPoll(slot)`, in this order, one event per call:
1. If `rtTcp68PbLive` and the PB is no longer pending: `res = rtAt68Result(pb)`, `rtTcp68PbLive = false`. Op 1: `res == 0` → arm the receive, return `rtTcpEvOpened`; else tear down (release) and return `res`. Op 2: return `rtTcpEvSent` (a send error `res < 0` on an open connection is reported as `rtTcpEvClosed` after a release — ponytail: a failed send means the connection is gone). Op 3: nothing to report (the receive reports the end).
2. If `rtTcp68RcvLive` and the receive PB completed: `rtTcp68RcvLive = false`; `res == 0` → `rtTcp68RcvGot = peekw(pb + tcpRcvRcvBuffLen)` (MacTCP writes the actual count back into `rcvBuffLen`), return `rtTcpEvReceived`; `connectionClosing`/`connectionTerminated`/any error → return `rtTcpEvClosed` (tcp.cla releases).
3. Return `rtTcpEvNone`.

`rtTcpDevRecvLen`/`RecvPtr`: `rtTcp68RcvGot` / `ptr(rtTcp68Rcv[slot])`.

`rtTcpDevSend(slot, p, n)`: `BlockMoveData(p, ptr(rtTcp68Snd[slot]), n)`; WDS: `pokew(wds + 0, n)`, `pokel(wds + 2, rtTcp68Snd[slot])`, `pokew(wds + 6, 0)`; zero `rtTcp68Pb`, `csCode = tcpSend`, `tcpStream`, `ulpTimeoutValue = 30`, `ulpTimeoutAction = tcpUlpAbort`, `validityFlags = 0xC0`, `pushFlag = 1`, `wdsPtr`; `PBControlAsync`; `PbLive/PbOp = 2`. `rtTcpDevSendBusy` = `rtTcp68PbLive and rtTcp68PbOp == 2`.

`rtTcpDevClose(slot)`: requires `rtTcp68Pb` not live (tcp.cla guarantees the send drained); zero, `csCode = tcpClose`, `ulpTimeoutValue = 10`, `ulpTimeoutAction = tcpUlpAbort`, `validityFlags = 0xC0`; `PBControlAsync`; `PbLive/PbOp = 3`, `rtTcp68Closing = true`.

`rtTcpDevRelease(slot)`: if a stream exists — sync `tcpAbort` through `rtTcp68Aux` (zero, refnum, csCode, stream); then wait for both async PBs to leave `ioResult == 1` (a bounded spin: up to 120 iterations of checking, each iteration calling `Delay(1)`? No `Delay` here — spin on `rtAt68Pending` with a counter of 100000; the abort completes them synchronously per the guide's "all pending commands are returned"; the probe wave (Task 8 P4) confirms). Then sync `tcpRelease` through the aux PB (returns the stream buffer), clear the stream, dispose the seven blocks (keep nothing allocated for idle slots — spec §5.3), reset the flags.
