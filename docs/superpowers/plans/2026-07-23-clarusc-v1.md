# clarusc v1 (check-only) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `clarusc` — a check-only Clarus compiler written in Clarus, producing diagnostics byte-identical to the Go `clarus check` over the whole corpus, verified by a differential harness.

**Architecture:** Two phases. Phase A adds four language precursors to the GO compiler (order-independent functions, include, 255-byte cap, `run --`), each with reference updates. Phase B builds clarusc as ~8 `.cla` modules stitched by `include`, using index-linked typed arenas (Clarus has no recursive types). **Order-independent functions is the load-bearing precursor:** recursive-descent parsing and the checker are mutual recursion (`parsePrimary`↔`parseExpr`, `checkExpr`↔`checkBlock`), which the language rejected under strict declare-before-use — Task 0 fixes that before any clarusc code is written. Each clarusc module is a port of a specific, already-reviewed Go source file — **that Go file is the byte-exact spec** — and each is verified by a complete Clarus test-driver program run through `clarus run`, with a hand-computed golden. The final tasks wire the whole compiler to a differential harness that diffs clarusc against the Go compiler across every corpus file.

**Tech Stack:** Go compiler (existing) for Phase A + the differential harness; Clarus (the language) for clarusc itself; the host runtime.

## Global Constraints

- **Spec:** `docs/superpowers/specs/2026-07-23-clarusc-v1-design.md`. **Language authority:** `docs/clarus-language-reference.md`. **Byte-exact parity is the contract** — clarusc's diagnostics must equal `clarus check`'s stdout byte-for-byte, same order, same `path:line:col: message` format, same exit code (0 clean, 1 any diagnostic), over the entire corpus. The Go compiler's wording is normative; when clarusc differs, clarusc is wrong (unless the Go compiler has a genuine bug — then fix Go with a test and note it).
- **Diagnostic ordering (verified: `internal/parser/parser.go:39`, `internal/driver/driver.go:29-36`, `internal/check/check.go`):** globally, **all parse-phase diagnostics come first (in include-expansion / DFS assembly order), then all check-phase diagnostics** — the checker runs one pass over every file's decls after all parsing. Per file: lexer diags, then the single fail-fast parse diag. clarusc must reproduce this two-phase global order, NOT a per-file lex/parse/check interleave. Neither compiler sorts or dedups diagnostics.
- clarusc source lives under `clarusc/` (Clarus files) with test drivers under `clarusc/test/`. Go additions follow existing `internal/…` layout.
- clarusc uses the full current language. Arena idiom: typed `list of ExprNode`/`StmtNode`/`DeclNode`/`Token`/`TypeInfo`, `int` indices, `-1` = nil, all field access through accessor functions, `next` sibling links for sequences, one global string-intern pool.
- Every clarusc module task ships a Clarus test-driver program (`clarusc/test/NAME_test.cla`) that `include`s the module + deps, exercises it, and `alert`s a deterministic representation; plus a `.out` golden; plus a Go-side runner that builds and runs it via `build.Build`/exec and diffs. Hand-compute goldens before running.
- gofmt/vet clean on Go code; `-std=c99 -Wall -Werror` stays clean; every reference edit that adds/removes a ```rust fence requires a reftest manifest check (Phase A includes it).
- **include rule (refinement of the spec's "at the include site"):** `include` statements appear at the TOP of a file, before any other top-level declaration. This keeps one-tree-per-file position mapping intact. A non-leading include is a diagnostic `include must precede other declarations`.

## Phase A — Go compiler language precursors

### Task 0: Order-independent functions

The language rejected mutual recursion (`func a` calling `func b` defined
later → `undefined: b`) under strict declare-before-use. Recursive-descent
parsing and the checker both require it. Make top-level functions visible
program-wide via a shallow signature pre-scan; keep types/records/enums/
consts/vars strictly declare-before-use.

**Files:**
- Modify: `internal/check/check.go` (the top-level walk in `Files`/`checkDecl`)
- Test: `internal/check/check_test.go`

**Interfaces:**
- Produces: two-phase top-level checking (the two-tier declare-before-use of
  reference Ch1) — **phase 1** walks top-level decls in order, registering
  each and enforcing type-layout ordering (record field types, enum members,
  function *signatures*, top-level var types may name only types declared
  before them); **phase 2** walks function/handler/every bodies against the
  FULL top-level scope, so a body may reference any function, variable, or
  type regardless of order. Duplicate names still error (`redeclaration of X`)
  in phase 1. This is the BROAD rule (bodies see the whole program), not
  functions-only — verified correct behavior per the reference.
- The diagnostic-order consequence (see Global Constraints below and Task 10):
  this does NOT change that check-phase diagnostics come after all parse-phase
  diagnostics; within checking, phase-1 signature errors precede phase-2 body
  errors.

package selfhost

import (
	"clarus/internal/build"

	"os/exec"
	"path/filepath"
	"strings"
	"testing"

// runClarusTest builds a clarusc test-driver .cla (which includes its module
// under test) and runs it, returning stdout. Fails on build or nonzero exit.
func runClarusTest(t *testing.T, claPath string) string {
	t.Helper()
	exe := filepath.Join(t.TempDir(), "drv")
	diags, err := build.Build([]string{claPath}, exe)
	if err != nil || len(diags) > 0 {
		t.Fatalf("build %s: err=%v diags=%v", claPath, err, diags)
	}
	out, err := exec.Command(exe).Output()
	if err != nil {
		t.Fatalf("run %s: %v", claPath, err)
	}
	return string(out)
}

func checkGolden(t *testing.T, claPath string) {
	t.Helper()
	want, err := os.ReadFile(strings.TrimSuffix(claPath, ".cla") + ".out")
	if err != nil {
		t.Fatal(err)
	}
	got := runClarusTest(t, claPath)
	if got != string(want) {
		t.Errorf("%s:\n got: %q\nwant: %q", claPath, got, want)
	}
}

func TestClarusModules(t *testing.T) {
	files, _ := filepath.Glob("../../clarusc/test/*_test.cla")
	for _, f := range files {
		f := f
		t.Run(filepath.Base(f), func(t *testing.T) { checkGolden(t, f) })
	}
}
